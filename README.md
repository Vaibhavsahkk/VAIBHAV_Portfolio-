# Vaibhav Kumar - Portfolio

This repository contains the source code for my personal portfolio, built to showcase my projects and experience in Machine Learning, Deep Learning, and Generative AI.

## Overview

The portfolio is a single-page application developed using vanilla web technologies. It highlights my technical background, including deep learning architectures (like MoE), quantum machine learning research, and full-stack AI platform development.

## Tech Stack

* HTML5 & CSS3
* Vanilla JavaScript
* Canvas API (for interactive background rendering)
* EmailJS (for serverless contact form submission)

## Local Development

To view the project locally, clone the repository and open the index.html file in any modern web browser. No build steps, package managers, or local servers are strictly required.

```bash
git clone https://github.com/Vaibhavsahkk/VAIBHAV_Portfolio-.git
```

## Deployment

This project is fully static and optimized for immediate deployment on platforms like GitHub Pages, Vercel, or Netlify.
